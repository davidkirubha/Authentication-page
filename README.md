# Authentication Page 🔐

A simple Login and Signup Authentication project built using HTML, CSS, and JavaScript. Users can create an account, store their details in Local Storage, and log in using their registered email and password.

## 🚀 Live Demo

[View Authentication Page](https://authentication-page-ivory.vercel.app)

## ✨ Features

- User Signup
- User Login
- Form validation
- Password confirmation
- Email and password verification
- Store user details using Local Storage
- Login validation using saved user details

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage
- JSON

## 📌 How to Run Locally

1. Clone this repository:
   `git clone YOUR_GITHUB_REPOSITORY_URL`
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
